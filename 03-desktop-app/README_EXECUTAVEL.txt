RH VALORACAO - APLICATIVO WINDOWS V5.6

Execute RH_Valoracao.exe com dois cliques.
O aplicativo inicia a interface local automaticamente.
O usuario final nao precisa ter Python instalado.

Para processar:
1. Selecione 1 Excel-base (.xlsx/.xlsm).
2. Selecione 1 ou mais folhas em PDF, ou ZIPs contendo PDFs.
3. Clique em Processar.
4. Baixe o Excel atualizado.

Os arquivos de cada execucao sao tratados em uma pasta temporaria local.
